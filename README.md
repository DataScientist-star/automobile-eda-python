# Automobile Dataset – Exploratory Data Analysis (EDA)

The notebook focuses on data cleaning, transformation, and visual exploration of automobile characteristics such as price, fuel efficiency, engine size, and manufacturer trends.


## Dataset Source
The dataset used is the **Automobile Dataset** (commonly used for machine learning and data analysis exercises).  
It contains information on vehicle specifications including price, engine size, fuel efficiency, body style, and manufacturer.

## Key Questions Answered
- What body styles dominate the dataset?
- How do the most expensive cars compare to the cheapest in terms of engine size and fuel efficiency?
- Which manufacturers produce the most fuel-efficient vehicles?
- Which vehicles have the largest engine capacities?
- Which manufacturer contributes the most models?
